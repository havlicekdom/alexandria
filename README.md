# Library App

Library App is a simple dashboard for borrowing books from a library and administration of the loans and the books.

## Installation

Simply run this command in the project root:

```bash
yarn
```

## Development

You're going to need a Node.js and MySQL server installed on your machine. Learn how to install Node.js [here](https://nodejs.org/en/) and about MySQL [here](https://dev.mysql.com/doc/mysql-installation-excerpt/8.0/en/installing.html).

After installing both, you can start the development by running in project root or in each application folder seprately:

```bash
yarn start
```

## Technology stack
* Lerna monorepo.

* Typescript on both server and client side applications.

* [React](https://reactjs.org/) + [Redux](https://redux.js.org/) on client.

* [NestJS](https://nestjs.com/) on server.

* [MySQL](https://www.mysql.com/) database.
